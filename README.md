# U-Net Models

## Описание 

> Данный проект преследует цель реализовать собственную U-Net модель и применить ее в задаче сегментации изображений. В качестве baseline для сравнения взята архитектура U-Net без skip-connections. 


## Обучение
- Model: StupidUnet, UNet, ResNetUNet
- Optimizer: AdamW (`lr=0.0001`, `weight_decay=1e-4`)
- Loss: CrossEntropyLoss
- Scheduler: ReduceLROnPlateau
- Early stopping: patience=`8`

## Выводы

	Из данных в таблице выше можно сделать однозначный вывод, что skip-connections повышают
  качество модели и улучшают ключевые метрики. Особенно это заметно именно на задаче многоклассовой
  классификации, где различаются фон, объект и его граница. Также значительный рост заметен при использовании 
  resnet-34 в качестве encoder части модели. Возможно, при использовании более тяжелой resnet-50 можно 
  будет еще значительнее повысить валидационные метрики.
